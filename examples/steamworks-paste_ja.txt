===== GAME NAME =====
ロータイド・サルベージ

===== SHORT DESCRIPTION =====
引き潮のときだけ姿を現す、海辺の市場町を舞台にしたサルベージ・アドベンチャー。持ち時間は6時間。水に沈んだホイットローの大通りを歩き、運べるだけの物を拾い集め、潮が満ちる前に何を持ち帰るかを決めよう。

===== ABOUT THIS GAME =====
毎朝、海が引くと、市場町ホイットローが6時間だけ戻ってくる。濡れた大通りを歩き、肉屋の戸口に絡まった昆布をまたぎ、潮が町をさらっていく前に、何を波止場まで運ぶ価値があるかを決める。

戦闘はない。整理そのものが目的の「インベントリ・パズル」もない。制約は、時間と重さ、そして水がもう玄関の段まで来ているときに、礼拝堂の長椅子が本当にパン屋の扉を通るかどうか。それだけだ。

[b]できること[/b]
[list]
[*]潮時計を確かめて、ホイットローが廃墟ではなく「町」であるうちに歩き回る。
[*]商品、看板、手紙、家具をサルベージする。手元に残すか、売るか、店の再建に使うか。その選択がゲームのすべてだ。
[*]パン屋、ラジオ店、フェリーの切符売り場を再開させる。再建した店は、次の引き潮に残されるものと、満潮の波止場で待っている人を変えていく。
[*]帳簿、レシピ、書きかけのメモ。物を通して町を読み解く。洪水へと導くクエストマーカーはない。
[*]物語は約6～8時間でクリアできる。まだ歩きたい通りが残っていれば、クリア後はフリーロームの潮で何度でも戻ってこられる。
[/list]

[i]Dredge[/i] の雰囲気とサルベージ、[i]A Short Hike[/i] の短くも完結した散策、[i]Unpacking[/i] のように物で人生を語る手法が好きなら、きっと近い手ざわりを感じるはずだ。サバイバルでも、ローグライクでも、ホラーでもない。海は時計であって、怪物ではない。

Windows、macOS、Linux向けに2027年3月18日発売予定。

===== KEY FEATURES =====
- 目に見える潮時計：ゼロになったら、運べる物だけを持って帰る
- プレッシャーは戦闘ではなく、重さと戸口の幅
- 店を再建すると、その後の引き潮に残されるものが変わる
- 物が語るストーリー：マーカーの道しるべではなく、手紙、帳簿、看板
- 約6～8時間で完結するキャンペーンと、クリア後のフリーローム
- 港の鐘、雑音まじりのラジオ、小さなアコーディオンで作ったオリジナル音楽
