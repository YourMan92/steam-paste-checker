# Steam store-page field rules (verified Wed Nov 11, 2026)

| Field | Rule | Source / confidence |
|---|---|---|
| **Short description** | **Plain text only.** Line breaks, bullets and formatting "will not render properly." Brief synopsis. **No time-based text** ("Now Available," "Available on March 4th," "Prepurchase now"). | Steamworks docs, *Store Page Written Description*: https://partner.steamgames.com/doc/store/page/description (official) |
| Short description length | **300 characters** hard cap. The official doc only says "a few hundred characters"; 300 comes from the Steamworks editor counter and is documented by the community and tools (Crowdin's Steam JSON app enforces 300). Translations over the limit get **truncated**, and about 6 visible lines. **Our rule:** ≤ 300 code points, warn above 270. | https://store.crowdin.com/steam-json · https://www.steampageanalyzer.com/blog/steam-short-description-guide (secondary, consistent) |
| Links in descriptions | Since **Sept 2024**, no links to external websites, no embeds that mimic Steam's UI, and no links or embeds pointing at other games, in the short description, About, special announcement and awards sections. Plain-text mentions of comparable titles are fine. **Our rule:** never add a URL. Keep any existing `[url]` exactly and flag it if it points off Steam. | Valve announcement, summarized in the steampageanalyzer guide above. Re-check in the Steamworks docs before each job |
| **About This Game** | Long-form, rich formatting, images and GIFs. No character limit stated. Images < 5 MB each, total screenshots and GIFs < 15 MB. **Text inside images must be translated and re-uploaded per language**, so prefer textless images. | Steamworks docs (official) |
| Formatting tags | Keep `[h1]/[h2]/[h3] [b] [i] [u] [list] [olist] [*] [img] [url] [hr] [p]` exactly. The JSON export and import must keep keys and tags identical. | gramshift / SteamLoc / WishlistLab descriptions (secondary) |
| Localizing text | Language drop-down at the top right of each text editor, or export the store page JSON, translate, and import. | https://partner.steamgames.com/doc/store/localization (official) |
| **Localized game name** | Set in **Steamworks Settings → General Application Settings**. Shown to users in that language, **used for search suggestions in that language**, and the base name stays as a fallback. Subject to the same limits as changing the game name. | Same Localization doc (official). Valve PDF: "Localized names get indexed on and off Steam" |
| Search aliases | Exists (seen on SteamDB as "Aliases"), **not in the Steamworks docs**. Suggest only, and tell the buyer to ask Steam Support. | Steam Discussions thread (unofficial, low confidence) |
| Tags | Chosen from Steam's global tag list and displayed in the user's language by Steam. **Not translated by the developer.** We only give tag-order notes. | Common Steam behaviour. Verify display with `?l=` |
| Language preview codes | `schinese`, `tchinese`, `japanese`, `koreana` (Korean is **koreana**). | Steam API language codes: https://partner.steamgames.com/doc/store/localization/languages |
| AI disclosure | The Content Survey's Generative AI section covers pre-generated content that ships "and is consumed by players," including **localization**. The survey question includes "the store page, and any Steam community assets or marketing materials." **The buyer must disclose AI-assisted store translation.** | https://partner.steamgames.com/doc/gettingstarted/contentsurvey (official) + r/gamedev quote of the survey text |

**Counting:** `check_paste.py` counts Unicode code points (`len()` in Python). A CJK character counts as 1, which matches how the editor counter behaves in practice. Still, tell the buyer to glance at the Steamworks counter after pasting.
